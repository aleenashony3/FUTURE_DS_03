# Bank Marketing Funnel Analysis

## Project Overview

This project analyzes bank marketing data to understand customer conversion, identify funnel drop-off points, and evaluate campaign performance using Python.

## Objectives

- Clean and structure the marketing data
- Analyze customer conversion rates
- Identify funnel drop-off points
- Compare conversion across contact channels
- Analyze campaign/contact frequency
- Compare monthly conversion performance
- Analyze previous campaign outcomes
- Identify opportunities to improve conversions
- Create a professional funnel analysis dashboard

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dashboard

The dashboard includes:

- Total prospects
- Converted customers
- Conversion rate
- Drop-off rate
- Contact → Customer funnel
- Conversion by contact channel
- Conversion by contact frequency
- Monthly conversion performance
- Previous campaign outcome
- Call-duration engagement analysis

## Key Analysis

The project focuses on the measurable funnel:

**Contacted Prospects → Converted Customers**

Traffic-to-lead conversion was not calculated because the dataset does not contain website traffic or lead-generation data.

## Project Files

- `bank_funnel_analysis.ipynb` — Python analysis and dashboard
- `bank_marketing_funnel_dashboard.png` — Final dashboard


## Outcome

The analysis provides data-driven insights into customer conversion and campaign performance that can help identify areas for improving marketing effectiveness.
